# Логово Знаний ИИ — Telegram-бот

## Возможности
- Обязательная подписка на канал `@logovoznani` с кнопкой проверки.
- ИИ-чат через OpenRouter и бесплатный роутер `openrouter/free`.
- Короткая история диалога в памяти процесса (сбросится при перезапуске Render).
- Генератор сюжетов и промтов.
- Роли: владелец, заместитель, администратор, пользователь.
- Админ-панель: `/admin`.
- Webhook для Render.

## Переменные Render → Environment
- `BOT_TOKEN` — токен бота от BotFather.
- `OWNER_ID` — твой Telegram ID.
- `WEBHOOK_SECRET` — 1–256 символов, только латинские буквы, цифры, `_` и `-` (лучше использовать длинную случайную строку).
- `AI_API_KEY` — API-ключ OpenRouter.
- `AI_MODEL` — `openrouter/free`.
- `AI_BASE_URL` — `https://openrouter.ai/api/v1`.
- `CHANNEL_USERNAME` — `@logovoznani`.
- `RENDER_EXTERNAL_URL` — Render обычно предоставляет эту переменную автоматически. Если задаёшь вручную, укажи полный адрес `https://logovo-ai.onrender.com` без завершающего `/`.

Код сам нормализует адрес webhook: понимает и полный URL с `https://`, и hostname без схемы. Не добавляй `https://` дважды.

## Подключение OpenRouter
1. Открой https://openrouter.ai/ и создай аккаунт с помощью родителя/опекуна, если для регистрации или условий сервиса это требуется.
2. Создай API key в кабинете OpenRouter.
3. Добавь его в Render как `AI_API_KEY`. Не присылай ключ в чаты и не добавляй его в GitHub.
4. Убедись, что `AI_MODEL=openrouter/free`, `AI_BASE_URL=https://openrouter.ai/api/v1`.
5. Сохрани Environment и сделай Manual Deploy.

`openrouter/free` маршрутизирует запросы только к бесплатным моделям. Доступность и лимиты меняются; бесплатные модели могут временно быть перегружены или недоступны. Не добавляй платные модели в fallback-массив.

## Проверка подписки
Бот должен быть администратором канала `@logovoznani`. Проверка выполняется через Telegram `getChatMember`. Если Telegram не может проверить участника, бот не открывает меню и показывает сообщение об ошибке.

## Проверка сервиса
Открой `https://logovo-ai.onrender.com/health`. Ожидается JSON со статусом `ok`.

## Команды
- `/start` — главное меню.
- `/ask вопрос` — задать вопрос ИИ.
- `/admin` — админ-панель.
- `/id` — показать Telegram ID.
- `/deputy TELEGRAM_ID` — назначить заместителя (только владелец).
- `/grantadmin TELEGRAM_ID` — назначить администратора (только владелец).
- `/removeadmin TELEGRAM_ID` — снять роль (только владелец).

## Бесплатный Render
Бесплатный Web Service может засыпать после периода бездействия. SQLite на файловой системе бесплатного сервиса может потерять данные при новом деплое/перезапуске. История ИИ хранится только в памяти процесса и сбрасывается после перезапуска.

## Важно
- Telegram Premium друга не даёт боту API-доступ к ИИ и не требуется для базовых функций.
- Не публикуй `.env`, `BOT_TOKEN`, `WEBHOOK_SECRET` или `AI_API_KEY`.
- Не добавляй секреты в GitHub.
